# AiStation （码枢）

**把多款 AI 编程工具，汇聚到一个开发工作台。 给所有 AI 编程 CLI 工具一个统一的家。**

一个桌面应用，把 Claude Code、Codex CLI、Gemini CLI、OpenCode 、Hermes 等命令行 AI 工具集中到一起：多标签终端、会话历史可回溯、Token 费用估算、代码片段随手复用——而且全部数据都留在你自己的电脑里。

---

## 为什么选 AiStation

### 🧠 多 AI 工具，一个窗口
同时跑 Claude Code、Codex、Gemini、OpenCode、Hermes每个工具一个标签页，互不干扰，鼠标一点就能切换。不用再开一堆终端窗口、不用记一堆启动命令。

### 📜 会话历史，秒级回溯
所有 AI 对话自动归档到本地数据库。哪天写的、改了哪个项目、聊了什么——一搜就出来。一键恢复任意会话，从上次断开的地方继续，不用从头复述需求。

### 💰 Token 花了多少，看得见
每个会话实时统计 Token 消耗和费用。日 / 周 / 月汇总，项目维度对比，谁烧钱一目了然。再也不用等到月底账单出来才吓一跳。

### 🧩 代码片段库
常用的 prompt、调试命令、脚手架代码，存进内置片段库。拖进终端就能用，团队共享也不在话下。

### 🗂️ 项目级记忆
每个项目有独立的 AI 上下文记忆。打开 A 项目，AI 自动记得这个项目的代码风格、技术栈、注意事项——不用每次重新介绍。

## 🔒 你的数据，只在你电脑上

这是 AiStation 最重要的设计原则：

- **完全本地运行**——所有会话、代码、Token 记录都存在你自己机器上的本地数据库里，不经过我们的服务器。
- **API Key 自己管**——密钥加密存储在本地系统凭据库（Windows Credential Manager / macOS Keychain），AiStation 不上传、不中转、不窥探。
- **无账号、无登录、无追踪**——不用注册，不用邮箱，没有埋点分析。装上就能用，断网也能用。
- **直接对接官方 API**——你的请求由本地 AiStation 直连 AI 厂商官方接口（Anthropic、OpenAI、Google 等），中间没有任何代理层。

**一句话**：你的代码、你的对话、你的 API 额度，都是你的，我们碰不到。

## 🚀 5 分钟上手

### 第 1 步：下载安装

到 Release 页面下载对应平台的安装包：

- **Windows**：`AiStation_x.x.x_x64-setup.exe`（推荐，自动安装）
- **macOS**：`AiStation_x.x.x_aarch64.dmg`（Apple Silicon）/ `x64.dmg`（Intel）
- **Linux**：`.deb` 或 `.AppImage`

装完打开，不需要注册任何账号。

### 第 2 步：填一次 API Key

首次启动会让你配置 AI 工具的凭证。三种方式任选：

1. **直接填 API Key**（最快，Anthropic / OpenAI / Google 等都支持）
2. **OAuth 登录**（部分工具支持，比如 OpenCode 的 `/connect`）
3. **留空，进 TUI 后用工具自己的认证命令**（比如 Claude Code 的 `/login`）

Key 存进系统凭据库，下次打开不用重填。

### 第 3 步：新建一个会话

1. 点左上角 **新建会话**
2. 选 AI 工具（Claude Code / Codex / Gemini / OpenCode……）
3. 选项目目录（AI 会在这里干活）
4. 点确认，终端里 AI 就起来了

开始聊吧。关闭窗口后，会话自动存档，下次在左侧"会话历史"里双击就能恢复。

## 适合谁用

- **同时用多个 AI CLI 的开发者**——厌倦了在多个终端窗口间切换
- **关心数据隐私的团队和个人**——不希望代码片段经过第三方云
- **想追踪 AI 开销的人**——需要项目维度的 Token / 费用报表
- **长期项目的维护者**——需要 AI 记住项目上下文，而不是每次重头讲
